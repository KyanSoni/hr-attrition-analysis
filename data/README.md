# Data

The data is not stored in this repository. Download it from Kaggle (a free account is needed):

**IBM HR Analytics Employee Attrition & Performance**
https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset

## How to prepare it

1. Download and unzip the file.
2. Rename the CSV (`WA_Fn-UseC_-HR-Employee-Attrition.csv`) to `hr_attrition.csv`.
3. Do not open and save it in Excel; import the untouched file.
4. Run the files in [../sql](../sql) in number order, importing the CSV after `01_create_table.sql`.

## About the data

The dataset is fictional, created by IBM data scientists. No real people are in it.
